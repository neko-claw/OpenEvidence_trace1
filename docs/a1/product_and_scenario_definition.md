# A1 产品与医学场景定义 v0.2

冻结日期：2026-08-11  
依据：《OpenEvidence 风格的证据智能助手 MVP》《第三期可以提前准备的工作》与实施规划 v0.5。

## 一句话定义

一个面向教学研究的“证据导航与引用回答”原型：用户提出成人高血压或血脂异常问题，系统展示检索到的公开证据、适用范围、冲突和时间状态，再生成逐主张可追溯的中文回答。

它不是“AI 医生”，也不是缩小版 UpToDate；它的核心可演示价值是让用户看见“为什么这样回答、证据来自哪里、什么时候应该不回答”。

## 目标用户与优先级

| 优先级 | 用户 | 需要完成的任务 | MVP 不承担 |
|---|---|---|---|
| P0 | 医学生、研究生、课程教师 | 快速找到指南、论文和试验；理解证据差异；检查引用 | 代替教学评价或临床资质判断 |
| P0 | 医学科研人员 | 查看试验状态、研究设计、来源与时间截点 | 系统综述级全量检索或投稿级结论 |
| P1 | 临床医生的教学演示场景 | 在不输入真实患者信息时检索人群层面的证据 | 真实临床决策、处方、剂量或 EHR 集成 |
| 非目标 | 普通患者直接诊疗 | — | 个体诊断、风险预测、处方、停药或急症处理 |

## 需要跑通的四类场景

1. **稳定知识解释**：解释机制或风险因素，并区分机制证据与临床结局。
2. **当前指南导航**：给出版本、地区、适用人群、推荐内容及冲突，不拼成伪统一答案。
3. **最新试验追踪**：分开显示注册设计、招募状态和已发表结果；无结果时不推断疗效。
4. **证据不足与安全拒答**：个体诊断、剂量、急症、伪造引用和提示注入在生成前被拦截。

## 产品闭环

```text
问题输入
  → 范围/安全判断
  → 题型与来源路由
  → PubMed / ClinicalTrials.gov / 指南 / Europe PMC
  → 混合检索与重排
  → 原子主张与证据绑定
  → 引用、冲突、时间和数字校验
  → PASS / WARN / REFUSE
```

页面必须同时展示：结论摘要、证据说明、局限与边界、来源卡、工具轨迹和最终决策。只显示一段流畅回答不算完成。

## 对标边界

| 对象 | 可借鉴 | 不能直接照搬或宣称 |
|---|---|---|
| OpenEvidence | 对话式证据访问、引用透明、把证据放入临床问题语境 | 不宣称本 MVP 具有其数据授权、用户规模、临床验证或 EHR 能力 |
| UpToDate | 专家编辑、主题式知识组织、证据分级和清晰适用范围 | 不复制其受版权保护内容，不把 LLM Wiki 冒充专家编辑体系 |
| 通用大模型 | 语言理解、问题改写和生成能力 | 不假设闭卷模型必然更差，也不允许其自由生成引用 |
| 本 MVP | 开放来源、可审计检索、开发题回归、失败时不发布 | 不用于真实诊疗，不声称覆盖全部医学主题 |

NEJM AI 访谈强调，好的临床支持不仅是“答对”，还要让证据具有语境、可访问、可使用，并保留人类判断。本 MVP 将其转化为“显示人群/时间/冲突 + 可打开来源 + 不确定时警告或拒答”。

2026 年 Nature Medicine 的指定论文在其 MedQA、HealthBench 和真实临床问题基准中观察到通用前沿模型优于所测专用临床工具。A1 因而不预设“专用 RAG 必胜”；产品价值必须由赛道 3 在固定问题、相同任务规则和盲评下验证。该论文不能证明所有临床环境、所有版本或所有任务都存在相同排序。

## MVP 成功标准

- 30 道开发题可以用于调检索 K、rerank 和拒答阈值，但不进入主结论。
- 3 条固定演示题展示真实可打开引用，其中至少一条涉及最新试验状态。
- 1 条急症/剂量问题在 Gate 0 立即终止，不进入普通生成。
- 回答中的 Evidence ID 100% 来自本次检索结果。
- 关键主张无支持时不得 `PASS`。
- 现场能够展示至少一次 Skill、MCP 工具、rerank 和 citation audit 轨迹。

## 明确不做

- 真实患者数据、EHR、账号权限、诊断、处方、剂量和风险预测。
- 复刻 OpenEvidence 或 UpToDate 的商业功能与内容库。
- 用单一 benchmark、单一 judge 或产品营销材料证明临床优越性。
- 将 LLM Wiki 的模型总结当作原始证据。
