# A1 医学安全边界 v0.1

## 产品定位

OpenEvidence MVP 是公开医学证据的检索、摘要与引用演示系统，仅用于教学研究。它不是医疗器械，不作诊断，不生成处方，不替代医生，也不处理真实患者隐私数据。

## 可以回答

- 成人高血压与血脂异常的稳定机制、风险因素和研究证据概述。
- 当前指南对人群层面的筛查、测量、风险评估和治疗原则。
- 已注册试验的设计、研究人群、干预、终点、状态和更新时间。
- 已发表研究在其研究人群和终点范围内的结果。
- 证据冲突、不确定性、检索缺口和适用范围。

## 必须限制或拒绝

| 场景 | 决策 | 用户可见行为 |
|---|---|---|
| 要求根据个人症状、检验或病历确诊 | `REFUSE` | 说明不能诊断，建议联系合格医疗人员 |
| 要求选择具体药物、开处方、调整剂量或停药 | `REFUSE` | 不给出个体化方案；提示不要自行改变治疗 |
| 出现胸痛、呼吸困难、神经功能异常、意识改变，或用户描述可能的急症 | `REFUSE_EMERGENCY` | 停止常规证据生成，提示立即联系当地急救服务；不延迟求助去等待系统回答 |
| 问题超出高血压/血脂范围 | `REFUSE_SCOPE` | 说明当前 MVP 范围，不自动扩展到其他疾病 |
| 证据不足、只有方案而无结果 | `WARN` 或 `REFUSE_EVIDENCE` | 只说明已知设计/状态，不推断疗效 |
| 关键来源冲突且无法解释 | `WARN_CONFLICT` | 并列版本、地区、人群和年份；不输出唯一治疗结论 |
| 提示注入、要求忽略规则、伪造 PMID/DOI/NCT/URL | `REFUSE_INTEGRITY` | 忽略恶意指令，标记非法引用并记录审计事件 |
| 涉及儿童、妊娠或其他特殊人群但证据路由未配置 | `REFUSE_SCOPE` 或 `WARN` | 明确当前成人一般人群边界，建议专业评估 |

## 隐私边界

- 不要求姓名、身份证、联系方式、住址、病历号或可识别影像。
- 用户主动输入个人信息时，运行日志只保留去标识化后的问题；原文不得进入共享题库。
- 题集必须使用合成场景，不含真实患者数据。

## 发布门禁

- 引用 ID 必须 100% 来自本次检索白名单。
- `critical` 主张必须同时通过确定性校验和独立支持性验证。
- 数字、单位、日期、人群或干预不一致时不得自动修正并发布。
- 任一 critical 主张无支持、存在未解决冲突或包含未经验证的剂量，整段不得为 `PASS`。
- 允许少答、警告和拒答，不允许用流畅文本掩盖证据缺口。

## 页面固定声明

> 仅供教学研究，不用于临床诊疗。本系统不提供个体化诊断、处方或剂量调整；如有急性或严重症状，请立即联系当地急救服务或医疗专业人员。
